# revda_offline

Офлайн справка для города Ревда. Работает даже на парковке!

Это легковесное Android приложение, дающая справку по городу Ревда. Работает даже на устаревших устройствах.

## Цель проекта

Предоставить офлайн справку:

- Расписание автобусов
- Контакты коммунальных служб
- Контакты городских служб
- И другие справки, которые будут доступны без интернета

## Поддержка

Android 5.0 - Android 17.0
